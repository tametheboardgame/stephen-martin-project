# Stephen Martin Project

An adult satirical fictional universe spanning a rescue adventure game, comedy music and an illustrated comic.

## Development streams
- **Shared characters:** approved designs and reference artwork for Stephen, David, Paul and other characters.
- **Game:** Rescue Stephen Martin from China, mini-games, dialogue and multiple endings.
- **Music:** lyrics, musical prompts and album artwork.
- **Comic:** scripts, panels and published editions.
